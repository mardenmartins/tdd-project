## 🇧🇷 Português

### Sobre

Repositório reservado para estudos e práticas de **Test-Driven Development (TDD)** — Desenvolvimento Orientado a Testes.

A proposta do repositório é registrar experimentos e exercícios sobre o ciclo:

1. **Red:** escrever um teste que falha.
2. **Green:** implementar o mínimo necessário para fazê-lo passar.
3. **Refactor:** melhorar o código mantendo os testes aprovados.

### Objetivos de aprendizagem

- Compreender o ciclo Red-Green-Refactor;
- Praticar a escrita de testes automatizados;
- Desenvolver código de forma incremental;
- Refatorar com segurança apoiado por testes.

> Este repositório está em preparação. Os exemplos e tecnologias serão documentados à medida que forem adicionados.

## 🇺🇸 English

### About

A study repository for **Test-Driven Development (TDD)** exercises and experiments.

The central practice is the Red-Green-Refactor cycle:

1. **Red:** write a failing test.
2. **Green:** implement the minimum code required to pass it.
3. **Refactor:** improve the implementation while keeping tests passing.

> This repository is being prepared. Examples and tools will be documented as they are added.
